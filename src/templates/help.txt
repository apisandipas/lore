lore: typed project notes linked to the code they govern

Usage: lore <command> [args] [options]

Commands:
  init                Write .lore/ (schema, templates, WORKFLOW.md) and check
                      that the lore-* skills are installed
  context <file>...   Notes that govern these files, most relevant first
                        --full            include note bodies
                        --budget <tokens> cap the output (default 4000)
                        --session <id>    only notes this session has not
                                          been shown, or that changed since;
                                          prints nothing when there are none
                        --forget          with --session, start it over
  show <note>         A note with its links, backlinks, citations and anchors
  list                Every note, one per line
                        --type <type>     only notes of this type
                        --summaries       add each note's summary
  check               Report broken links, citations, anchors, schema errors,
                      superseding mistakes and spec drift (exit 1 if any)
  new <type> <title>  Create a note in the type's directory, numbered if the
                      type has an id
                        --supersedes <note> mark that note superseded and
                                            move its anchors (repeatable)
                        --link <field>=<note>
                                            link that note in the field, for
                                            example specs=auth (repeatable)
  set <note> <field>=<value>...
                      Change frontmatter fields, checked against the schema;
                      field+=value adds to a list field
  tick <note>         Tick the note's first open checklist item and name the
                      next one
  freeze <note>       Record the current version of every spec the note links
                      to; check then reports when one changes
  next                What to do next, read from spec and effort state, and
                      the lore-* skill that does it
  graph [<note>]      Write the notes as an interactive graph, one HTML page,
                      and print its path; with a note, open focused on it
                        --out <file>      write the page here (default: the
                                          temp directory)
                        --depth <n>       links out from the note (default 2)
                        --open            open the page in the browser
  help                Show this help
  version             Print the version

Every command but help and version takes --json.
Notes link with [[name]]; code cites a note with lore:<name>.
